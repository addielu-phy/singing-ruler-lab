一把尺，為什麼會「唱歌」？

從彈性、慣性與邊界條件出發，完整推導懸臂梁的固有頻率；再親手改變長度、厚度、材料與模態，看公式如何變成可觀察的聲音。

原題：一端固定的尺受敲擊後會振動並發出特徵聲音。研究聲音如何受到相關參數影響。

FUNDAMENTAL RESULT

f1 = 0.16154 hL2 √E / ρ

細長、均勻、線性彈性的長方形懸臂梁；SI單位下得到Hz。

L平方反比 h近似正比 E / ρ平方根

THEORY

  1. 彎曲造成回復力
  2. 質量造成慣性
  3. 固定—自由邊界選出模態

從最基本的原理

三步走到懸臂梁頻率公式

先把尺想成一排彼此連在一起的小質點：每一段都會被彈性拉回，也都因為有質量而不願立刻改變速度。看懂「彈性＋慣性＋兩端限制」，頻率公式就不再像突然冒出來。

先記住一條故事線： 壓彎尺 → 尺產生回復作用 → 每一小段開始加速 → 固定端與自由端只允許某些振動形狀 → 每個形狀有自己的頻率。

90-SECOND VISUAL GUIDE

先看尺怎麼動，再讀公式

按1、2、3逐步閱讀，或讓動畫自動播放。圖中的位移與時間都經過視覺放大，重點是因果關係，不是實際比例。

第1步：先把自由端向下壓。彎曲是被視覺放大的概念示意。

想像一下：塑膠尺彎得越厲害，手感是不是越「硬」、越想彈回來？

第1步：把「彎曲」翻成回復作用

用 w(x,t) 表示尺在位置 x、時間 t 的上下位移。曲線彎得多不多，可用它對位置的二階變化表示。材料越硬（E大）、截面越難彎（I大），內部彈性彎矩就越大。

彎曲更明顯→彎矩更大→更想彈回
M = −EI ∂2w / ∂x2

這一步得到：知道尺為什麼有回復作用，但還不知道它會以多快的速度振動。

放手後，尺為什麼不會停在原位，而是衝過平衡位置、來回擺動？

第2步：對每一小段使用 F = ma

相鄰小段的彎矩不完全一樣，會先形成剪力；相鄰位置的剪力再有差異，才造成某一小段的淨力。每一小段又有質量，所以淨力使它產生上下加速度；它衝過平衡位置則是慣性的結果。

∂²w/∂t²：上下加速度∂⁴w/∂x⁴：彎矩經過兩次沿尺位置的比較，得到淨力
EI ∂4w / ∂x4 + ρA ∂2w / ∂t2 = 0

白話翻譯：彈性造成的淨力＋質量造成的慣性反應＝0。這就是「連續版」的彈簧振子方程。

這一步得到：有了描述整把尺如何運動的方程，但它仍允許很多種數學解。

吉他弦不是任何頻率都能形成穩定駐波；一端固定的尺也一樣。

第3步：用兩端限制篩選「允許的形狀」

桌邊的固定端既不能上下移動，也不能轉動；自由端沒有外加彎矩與剪力。只有同時滿足這四項條件的振動形狀能長久存在，我們稱它們為模態。

固定端位移 = 0固定端斜率 = 0自由端彎矩 = 0自由端剪力 = 0
cosh βn · cos βn = −1

βn 可把它想成「第 n 種允許形狀的編號」。第一個是1.8751，代回運動方程就得到第一模態頻率。

fn = [βn2/(2πL2)] √(EI/ρA)

這一步得到：邊界條件給出 βn，運動方程則把它變成真正的頻率。

目前顯示第1步：彎曲產生回復作用。

03 · 兩端限制 → 模態

哪些形狀與頻率真的被允許？

cosh βn · cos βn = −1

四個邊界條件篩出離散的 βn。

一口氣串起來：材料與截面決定「多難彎」；密度與截面積決定「多難加速」；長度與兩端限制決定「允許哪種振動形狀」。

直觀模型：等效彈簧與等效質量

自由端受力 F 時，靜態位移是：

δ = FL3 / (3EI)

因此等效剛性 keff = 3EI/L3。採用靜態自由端載荷的撓曲形狀作第一模態試函數時，廣義質量約為 0.236ρAL，得到：

f ≈ 0.5674 L−2 √(EI / ρA)

精確係數是0.5596，這個直觀模型只差約1.40%。

完整推導：分離變數與四個邊界條件

令 w(x,t)=X(x)T(t)，代入梁方程後，時間方程與空間方程分離：

T̈ + ω2T = 0　；　X⁗ − λ4X = 0

固定端不能位移也不能轉動；自由端沒有彎矩也沒有剪力：

X(0)=X′(0)=0；X″(L)=X‴(L)=0

非零解要求 cosh βn cos βn=−1，其中 βn=λnL。

ωn = βn2L−2√(EI/ρA)　；　fn=ωn/(2π)
長方形尺：為什麼寬度消失？

沿厚度方向彎曲時，截面積與截面二次矩是：

A=bh　；　I=bh3/12

所以 I/A=h2/12，寬度同時增加剛性與質量，兩者在理想頻率公式中抵消：

fn = [βn2/(4π√3)] · (h/L2) · √(E/ρ)
注意：這裡的 h 是「彎曲方向的尺寸」。若把尺轉90°側彎，原本的寬度可能變成新的彎曲厚度。

對照簡報實驗

四個變因，應該怎麼判讀？

理論給的是可被證偽的趨勢；實驗則必須控制其他參數、標單位並報告不確定度。

振幅

力影響音量，不直接進入頻率

δ=FL³/(3EI)

簡報實際控制的是釋放高度，不是直接量力。小振幅下它改變初始條件；大振幅才可能因幾何非線性改變頻率。

長度

畫 f 對 1/L² 應為直線

f=m(1/L²)

斜率 m=Cnh√(E/ρ)，不是沒有單位的數。夾具造成的有效長度誤差會被平方放大。

厚度

細梁正比，厚梁逐漸偏離

fRR≈fEB/√[1+(Qn/12)(h/L)²]

Qn=∫(φ′n)²du/∫φn²du，使用EB懸臂模態作Rayleigh–Ritz試函數，只近似加入轉動慣量；它不是完整Rayleigh梁或Timoshenko梁特徵解。簡報照片的cm標示與圖軸mm不一致，應先修正單位。

材料

真正比較的是 √(E/ρ)

f∝√(E/ρ)

比較不鏽鋼與塑膠時，厚度、長度、彎曲方向與夾持方式都要相同；否則斜率差不能只歸因於材料。

簡報斜率的物理意義

簡報的兩條 f–1/L² 擬合斜率為3330.49與1189.45 Hz·cm²；斜率比為2.800。若厚度相同，代表兩者的 E/ρ 比約為7.840，而不是只說「材料不同」。

模型邊界

這個模擬沒有假裝解決所有聲學

畫面展示的是梁的固有振動，不是把所有真實效應塞進一個看似精確的動畫。

模型包含

  • 均勻長方形截面
  • 固定—自由邊界
  • 前四個彎曲模態
  • Euler–Bernoulli精確特徵根
  • 可選EB模態Rayleigh–Ritz轉動慣量近似

模型忽略

  • 夾具滑動與柔性
  • 材料阻尼、空氣附加質量
  • 完整Timoshenko剪切效應
  • 非線性大振幅與碰撞
  • 真實麥克風、房間與聲輻射

視覺與聲音

  • 動畫時間不是SI時間
  • 動畫振幅為視覺放大
  • 純音按鈕只播放單一理論頻率
  • 寬度仍可能影響音量
  • 高模態可能超出可聽範圍
